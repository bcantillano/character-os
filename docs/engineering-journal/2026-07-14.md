## Architectural Decisions

### Confirmed

1. **Phase 1 MVP** — Text-only CLI chat. Voice deferred to Phase 1b (TTS output, no STT).
2. **Tech stack** — Python 3.11+, SQLite for long-term persistence, provider-agnostic `llm/` package.
3. **Default LLM** — OpenAI for Phase 1. Character Brain never imports OpenAI directly; only `llm/providers/openai.py` may. Anthropic/Ollama swappable via abstract provider interface.
4. **Emotional drives** — Phase 1 uses Curiosity, Trust, Excitement, Fear, Confidence, Energy (each 0.0–1.0). No valence/arousal model. Influences decision, dialogue, and future behavior.
5. **Time ticks** — Present in Phase 1; update internal state only (emotional decay/recovery, energy, goal progression, memory importance, relationships). **No unprompted CLI speech.** Proactive outward Act deferred to embodiment phases.
6. **Persistence split** — Long-term memory (names, preferences, experiences, relationship history) persists across sessions. Conversation state (topic, recent dialogue, temporary context) exists only during the active interaction.
7. **Relationships** — Minimal in Phase 1; trust and history stored as long-term relationship state.
8. **Internal Thoughts** — In Phase 1. Private monologue before response generation.
9. **Decision vs behavior** — `decision/` → `IntentDecidedEvent`; `behavior/` executes (speak, wait, update_state).
10. **Event-driven architecture** — All modules publish/subscribe via `events/`.
11. **Data-driven content** — YAML characters/worlds; Markdown prompts; dynamic loading.
12. **Knowledge vs Memory** — Knowledge = static YAML; long-term memory = persisted facts; conversation state = session-only.
13. **Phase 1 folder structure** — `docs/PHASE_1_STRUCTURE.md` (updated for conversation.py, update_state action, openai provider).
14. **Character lifecycle** — Observe → Interpret → Reflect → Decide → Act → Remember. Documented in `docs/CHARACTER_LIFECYCLE.md`. Foundation for all future embodiments.
15. **Phase 1 success criteria** — Believable character, not chatbot: consistent personality, persistent memory, emotional consistency, world awareness, goal-driven conversation, natural curiosity, non-assistant behavior. After ~10 minutes user should say they met a character, not used an AI.
