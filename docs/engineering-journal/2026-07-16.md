## What We Learned

- Phase 1 gate from yesterday holds: successful human conversation + OpenAI path + SQLite long-term memory
- Spoken recall fails when memory is only soft flavor in the response prompt — speech needs an explicit “known person” block plus recall-question detection
- Incremental persist fits cleanly with a dirty-id set on `MemoryStore`: load clean from DB, mark dirty on add/update/decay, upsert only dirty rows
- Tick decay should update the in-memory store (and mark dirty) rather than decaying SQLite alone — otherwise cache and DB diverge
- `character-os` is not a global command — run from the repo after `source .venv/bin/activate` (or `python -m character_os.cli.chat …`). Do not paste markdown `#` comment lines into zsh
- Human OpenAI retest confirmed speech-memory polish: name appears in spoken dialogue, not only in `(thoughts)`
- Blind familiarity `+0.02` and never-updating `user_trust` made relationship state decorative — intent/tone/signals need per-turn deltas with caps
