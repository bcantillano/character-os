## Architectural Decisions

*Prior locks stand.* New implementation choices:

1. `brain/speech_memory.py` formats speech-specific memory context (extract name; harden prompt when user asks “remember / my name”)
2. Response prompt section renamed/emphasized: “Known facts about this person (MUST use when relevant)”
3. `MemoryStore` tracks `_dirty_ids`; `persist_runtime(..., only_dirty_memories=True)` upserts only dirty facts, then clears dirty
4. New facts written via `remember_fact` are added to the store as clean (already on disk); importance bumps mark dirty for later upsert
5. Time-tick importance decay runs on the in-memory store so dirty tracking stays consistent
