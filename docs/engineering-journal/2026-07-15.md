## What We Learned

- Repo previously had no `src/` — now full Phase 1 spine under `src/character_os/`
- macOS Homebrew Python requires a project venv (PEP 668); `.venv/` used for local install
- Synchronous in-process `EventBus` is enough for Phase 1 CLI
- Stub LLM prompt matching must check Response Generator before Internal Thoughts (section heading overlap)
- An event **bus** is publish/subscribe — modules never call each other directly
- Long-term memory and conversation state stay separate: SQLite holds durable facts/drives/relationships; `brain/conversation.py` is session-only
- Remember stage runs on `ResponseReadyEvent` (not a direct callback) to avoid duplicate turn recording
- Persistence growth is uneven: `emotional_drives` and `relationships` stay one row each (overwrite); `long_term_memories` appends notable facts only — not full chat transcripts
- Saves fire after interpret, tick, and response; `persist_runtime` currently upserts **every loaded fact** each time — that write amplification is the first real bottleneck as memory grows
- Session start loads all facts for a character into RAM; importance decays but rows are never deleted yet
- Prompt cost (feeding too much memory to the LLM) may matter before SQLite itself fails; we already only surface a small top slice for context

## Architectural Decisions

*Prior locks from 2026-07-14 stand.* Implementation choices:

1. **Tick interval default** — 30 seconds
2. **Default LLM** — `stub` for local/dev; `openai` via env when ready
3. **Session wiring** — `CharacterSession` owns bus + lifecycle
4. **Persistence** — `CharacterPersistence` + SQLite at `data/character_os.sqlite3`; tables for `emotional_drives`, `relationships`, `long_term_memories`
5. **Remember triggers** — persist after user interpret, tick, and `ResponseReadyEvent`
6. **Tests** — integration tests use `persist=False`; persistence tests use `tmp_path`
7. **Memory growth stance (discussed)** — intentional to store facts not transcripts; Phase 1 demos are safe at hundreds of facts; harden write path / pruning before multi-day attraction use
