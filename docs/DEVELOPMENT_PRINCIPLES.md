# Development Principles

This project values architecture over speed.

Every module should have a single responsibility.

Business logic should never exist inside prompts.

The Character Brain owns all persistent state.

LLMs should remain replaceable.

All systems should expose clear interfaces.

Favor readability over cleverness.

Write tests for public APIs.

Keep modules loosely coupled.

Favor composition over inheritance.

Avoid premature optimization.

Document architectural decisions.

Assume this project will eventually become much larger.
